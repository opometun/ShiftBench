\section{Research question}
Hybrid datasets, which combine real and synthetic data, are often used to address data-associated limitations in model performance and generalization. However, selecting an effective hybrid dataset configuration is costly when based on actual downstream performance, because it requires training a separate model for each candidate configuration. A more efficient alternative is to predict downstream performance. This study focuses on \textbf{distribution-shift-based prediction} with the following research question: 

\textit{Can pre-training shift quantification predict the utility of a hybrid dataset reliably and therefore replace naive selection among candidate configurations?}

\subsection{Shift quantification}
A distribution shift occurs when two data distributions differ. In machine learning (ML), this typically refers to the shift between the distribution a model is trained on (training distribution) and the distribution it will be applied to (inference distribution, approximated by the test dataset). Hybrid datasets are often motivated by the goal of reducing this distribution shift: Adding synthetic data to real data can enrich the training distribution in a controlled manner, improving coverage and diversity, and supporting generalization to shifted inference conditions. Conversely, adding real data to synthetic data can help anchoring the model in real-world statistics, reducing the reality gap and mitigating reliance on unrealistic or harmful artifacts. 

Beyond this general notion, a distribution shift can be decomposed into several distinct components. Following the formulation of \cite{liu2022}, a segmentation model can be expressed as $G(x)=C(F(x))$, where the classifier $C$ outputs the posterior probability $P(Y|F(x))$ for an input image $x$. Applying Bayes' theorem yields 
\begin{equation}
\label{eq:bayes_shift}
P(Y \mid F(x)) = \frac{P(F(x) \mid Y) \cdot P(Y)}{P(F(x))}.
\end{equation}
The Bayes decomposition exposes the distributions that may differ between datasets. Based on the affected distribution, we differentiate between five shift types, of which this study focuses on three: covariate shift, label shift, and representation shift.\footnote{Additional shift types include class-conditional representation shift, which affects the input representation for a specific class $P(F(x)|Y)$, and concept shift, which affects the labeling function $P(Y|F(x))$ or $P(Y|X)$. Class-conditional representation shift is excluded because this study quantifies the shift at the dataset level rather than per class. Concept shift is excluded because all datasets share the same semantic label definitions.} Inspired by \cite{dale2024}, we chose our shift quantification metrics considering four criteria: Each metric must be easy to calculate, correlate with model performance on test data, provide information about the source of the gap, and react to changes in data distribution as hybrid training configurations are adjusted. Based on the information used for quantification, we group the selected shift quantification metrics into three categories, each capturing a different aspect of the shift:

\textbf{Image-based metrics} quantify the covariate shift, that is, differences in the input distribution $P(X)$ that arise from changes in visual properties such as color and texture. These metrics operate on the raw images. This study considers two metrics that focus on a shift in color ($\text{js}_{\text{color}}$) and texture ($\text{js}_{\text{texture}}$) respectively. Covariate shift was quantified using Jensen-Shannon distance \eqref{eq:js} between the normalized mean histograms $p_{\text{train}}$, $p_{\text{test}}$. Per-image color histograms were computed in HSV space using density‑based histogram counts. Per-image texture histograms were computed using multiscale Local Binary Patterns (LBP) at two scales ($P=8$, $R=1$) and ($P=16$, $R=2$).

\begin{equation}
\label{eq:js}
\begin{split}
d_{\text{JS}}(p_{\text{train}}, p_{\text{test}})
= \sqrt{
\frac{1}{2} D_{\text{KL}}\!\left( p_{\text{train}} \,\middle\|\, m \right)
+
\frac{1}{2} D_{\text{KL}}\!\left( p_{\text{test}} \,\middle\|\, m \right)
}, \\
\text{with } m = \frac{1}{2}\left(p_{\text{train}} + p_{\text{test}}\right)
\end{split}
\end{equation}

\textbf{Label-based metrics} quantify the label shift, that is, differences in the class-label distribution $P(Y)$. These metrics operate on the segmentation masks. This study considers three metrics that focus on a shift in class frequency ($\text{js}_{\text{classFrequency}}$), class presence ($\text{js}_{\text{classPresence}}$), and scene complexity ($\text{js}_{\text{sceneComplexity}}$) respectively. Label shift was quantified using Jenson-Shannon distance \eqref{eq:js} between the normalized histograms $p_{\text{train}}$, $p_{\text{test}}$. The class frequency histogram of a dataset shows the fraction of all pixels belonging to each class. The class presence histogram of a dataset shows the share of image-level class occurrences attributable to each class. The scene complexity histogram of a dataset shows the distribution of distinct-class counts per image.

\textbf{Representation-based metrics} quantify the representation shift, that is, differences in the feature distribution $P(F(x))$. These metrics operate in a learned feature space on image representations produced by a feature extractor $F$. This study used two pretrained feature extractors: DINOv2‑Base \cite{oquab2024} for appearance‑focused representations and StreetCLIP \cite{haas2023} for semantic‑focused representations. They were selected because both were exposed to car-mounted street-view-like imagery during training, making them well aligned with this study's target domain. Representation shift was quantified using centroid distance \eqref{eq:centroid} and Fréchet distance \eqref{eq:frechet} \cite{NIPS2017_8a1d6947} between two distributions with means $\mu_{\text{train}}$, $\mu_{\text{test}}$ and covariance matrices $\Sigma_{\text{train}}$, $\Sigma_{\text{test}}$, computed in DINOv2-Base and StreetCLIP feature spaces. This yielded four metric variants: $\text{fréchet}_{\text{dinov2}}$, $\text{centroid}_{\text{dinov2}}$, $\text{fréchet}_{\text{streetclip}}$, and $\text{centroid}_{\text{streetclip}}$.

\begin{equation}
\label{eq:centroid}
d_{\text{centroid}}(\mu_{\text{train}},\mu_{\text{test}}) = \|\mu_{\text{train}} - \mu_{\text{test}}\|
\end{equation}

\begin{equation}
\label{eq:frechet}
\begin{aligned}
&d_{\text{Fréchet}}(\mu_{\text{train}},\Sigma_{\text{train}};\mu_{\text{test}},\Sigma_{\text{test}}) = \\
&\sqrt{
\|\mu_{\text{train}} - \mu_{\text{test}}\|^2
+ \mathrm{Tr}\!\left(\Sigma_{\text{train}} + \Sigma_{\text{test}} - 2(\Sigma_{\text{train}} \Sigma_{\text{test}})^{\frac{1}{2}}\right)
}
\end{aligned}
\end{equation}

\smallskip
The last representation-based metric considered in this study is \textbf{SADGE} (Structural and Appearance Domain Gap Estimator), which was shown to predict downstream model performance most reliably among the shift quantification metrics tested in \cite{bartkowiak2026}. SADGE differs fundamentally from the nine other metrics evaluated here: While all other metrics quantify distributional distance between datasets (by comparing dataset-level statistics in image, label, or feature space), SADGE computes pairwise similarity between individual images and aggregates these similarities into a dataset-level score. In our adaptation, we chose their retrieval-based comparison over their aligned comparison, because exact pairs are not available. Each test image is compared to ten randomly selected candidate images from the hybrid training dataset. The strongest appearance and geometry match per test image is retained. Appearance similarity is measured using cosine similarity between DINOv3 \cite{simeoni2025dinov3} embeddings. Geometric similarity is measured using MASt3R \cite{mast3r} inlier counts. These per-image scores are averaged (to obtain dataset-level appearance similarity $\bar{A}$ and geometry similarity $\bar{G}$), standardized using z-score normalization \eqref{eq:zscore}, and fused through the pre-calibrated linear-bilinear model \eqref{eq:sadge} provided in \cite{bartkowiak2026}.

\begin{equation} \label{eq:zscore}
\begin{aligned}
\hat{A} &= \frac{\bar{A} - \mu_A}{\sigma_A}, && \text{with } \mu_A = 0.6359, \, \sigma_A = 0.1918 \\
\hat{G} &= \frac{\log(1+\bar{G}) - \mu_G}{\sigma_G}, && \text{with } \mu_G = 7.9420, \, \sigma_G = 1.7384
\end{aligned}
\end{equation}

\begin{equation}
\label{eq:sadge}
\begin{split}
\text{SADGE}(\text{ds}_\text{test}, \text{ds}_\text{train}) = a \cdot \hat{G} + b \cdot \hat{A} + c \cdot \hat{G} \cdot \hat{A}
\\
\text{with } a=0.0\text{, } b=1.8548\text{, } c=1.3399
\end{split}
\end{equation}

\section{Related research}
To the best of our knowledge, this is the first systematic assessment of distribution-shift quantification to determine the utility of hybrid image datasets before model training. However, recent research explored closely related ideas, with a primary focus on shift quantification \cite{bartkowiak2026, DetectShift, duminil2024, duminil2025, shiftForModelUtility, renza2024, dale2024, li2025}, shift reduction \cite{abramov2020, liu2022_labelShift, zhang2020}, or shift analysis \cite{UrbanSyn}.

% SADGE
\cite{bartkowiak2026} share our motivation for using shift quantification, namely to assess the utility of the training dataset before actual model training. However, while they focus on purely synthetic training datasets, we generalize to hybrid configurations. \cite{bartkowiak2026} distinguish "appearance" metrics, which assess whether synthetic images look domain-realistic, from "geometry" metrics, which assess whether they preserve spatial scene structure. Their experiments reveal that their combined similarity score $\text{SADGE}$ is a more reliable, dataset-agnostic predictor of downstream performance than any single-modality metric tested. Given this strong reported performance, we include SADGE as a benchmark metric in our study. 
While their metric taxonomy differs from ours, we can roughly map our categories onto theirs: Our image- and representation-based metrics correspond to their appearance category. $\text{SADGE}$'s geometry score is the only metric in our study falling under their geometry category. Our label-based metrics, however, capture a novel shift dimension. 

% DetectShift
\cite{DetectShift} introduce DetectShift, a framework that unifies the quantification of five shift types (joint $P(X,Y)$, feature $P(X)$, label $P(Y)$, and both conditional shifts $P(X|Y)$ and $P(Y|X)$) using Kullback-Leibler (KL) divergence. The authors demonstrate their framework in an experiment structurally similar to our study, although in an image classification setting: A shift between source and target distributions is modeled by progressively mixing in samples from a second dataset in one distribution while keeping the other fixed to a single dataset. The resulting shift score is then related to model performance. 
However, the purpose of this analysis differs: \cite{DetectShift} use shift quantification to guide targeted domain adaptation across varying shift strengths, and hence, vary the ratio of two real datasets in the test dataset. We instead use shift quantification to assess the utility of hybrid datasets for model training, and hence, vary the synthetic-to-real ratio in the training dataset.
Both frameworks come with their own advantages and limitations: DetectShift’s unified KL-based measure allows shift magnitudes to be compared meaningfully across shift types - a property our framework currently lacks. However, their framework requires training a classifier to obtain magnitude scores, while ours relies on pretrained models at most. 

% Texture-based
\cite{duminil2024, duminil2025} quantify the realism (termed “fidelity”) of synthetic street-scene images via texture and frequency analysis: global texture using the gray level co-occurrence matrix (GLCM) and derived Haralick features, local texture using local binary patterns (LBP), and frequency analysis using the discrete wavelet transform (DWT) \cite{duminil2024} or discrete cosine transform (DCT) \cite{duminil2025}. Most fidelity score computations require training a binary classifier on the GLCM, LBP, or DWT/DCT representations of each original image to distinguish real from synthetic images. Only the Haralick-based score requires no training. Across both the individual \cite{duminil2024} and fused \cite{duminil2025} fidelity scores, synthetic images tend to exhibit different texture properties than real ones. This motivates the inclusion of $\text{js}_{\text{texture}}$ in our study. Similar to \cite{bartkowiak2026}, their fused fidelity score yields a more reliable predictor of downstream performance than any single metric alone.

% utility of trained model
\cite{shiftForModelUtility} apply shift quantification to predict the utility of a trained model when applied to a new medical site. All evaluated shift quantification metrics use the trained model's output or internal feature representations of in-domain and target-domain data. Their proposed metric, Fréchet Domain Distance (FDD), produces shift scores with the highest correlation to the observed drop in model performance. Like $\text{fréchet}_{\text{dinov2}}$ and $\text{fréchet}_{\text{streetclip}}$, FDD quantifies the shift between feature representations using the Fréchet distance. The key difference is the feature source: FDD uses attention-selected features from the trained model itself, while our metrics use embeddings from an external, pretrained feature extractor.

% Class-wise
\cite{renza2024} emphasize that a distribution shift is non-uniform: Different corruptions affect different classes to different degrees. They repurposed the Cumulative Spectral Gradient (CSG) metric to quantify shifts between image-classification datasets by measuring class-wise separability between original and corrupted data. Similar to our representation-based metrics, CSG relies on a pretrained feature extractor rather than raw pixel or label statistics. However, \cite{renza2024} operate at the class level to isolate which classes and corruptions drive a shift within a single dataset, whereas we quantify shifts at the dataset level to assess the overall utility of a hybrid dataset.

% no inference dist required
\cite{dale2024} propose a framework for assessing a training dataset’s utility that bypasses the need for knowing the inference distribution. Instead of measuring the gap between training and test sets directly, they compute the training dataset’s self-similarity in the input, feature, or prediction space. Self-similarity is defined as the average pairwise similarity between training instances. In their study, they evaluate seven mixture-based data augmentation strategies to extend a hybrid training dataset's diversity, with the goal of improving generalization to a real-only test set. They find that lower self-similarity in the input and feature space corresponds to better downstream performance, whereas self-similarity in the prediction space shows no such relationship. Hence, self-similarity metrics present a promising direction for future work that addresses our study’s limitation of relying on a known inference distribution.

% NLP domain shift quantification
\cite{li2025} apply shift quantification between two datasets via statistical hypothesis testing in the field of Natural Language Processing (NLP). They consider a shift in word frequency, sentence-level representation, and label frequency. All shift metrics show statistically significant correlation with cross‑domain performance degradation. Their study shows that robust shift‑quantification methods have value well beyond the scope of our work, highlighting applicability in other ML domains such as NLP.

% domain adaptation via color alignment
\cite{abramov2020} show that aligning color statistics (the mean and covariance of RGB channels) and per-channel color histograms effectively reduces the domain gap between synthetic and real urban street scene datasets for object detection. This motivates the inclusion of $\text{js}_{\text{color}}$ in our study.

% domain adaptation via label alignment
\cite{liu2022_labelShift} address the problem of label shift in unsupervised domain adaptation for semantic segmentation of urban scenes by aligning the conditional distribution $P(X|Y)$ across domains so that the feature extractor leans class-conditional, domain-invariant representations, and rectifying the posterior probability $P(Y|F(x))$ to correct for the distortion introduced by the mismatched class frequencies. This motivates the inclusion of label-based metrics in our study.

% domain adaptation using both color and label alignment
\cite{zhang2020} target both color and label shift by aligning color (via gamut-based color constancy) and label distributions (via image-level or superpixel properties) between GTA-based synthetic data and Cityscapes for semantic segmentation. All three alignment strategies improve segmentation performance individually, with their combination yielding the largest gains. Their image-level label distribution measures the distribution of classes by pixel occupancy, which is similar to our dataset-level metric $\text{js}_{\text{classFrequency}}$. However, since they operate in an unsupervised domain adaptation setting, Cityscapes' label distribution is estimated rather than measured directly.

% comparative distribution analysis
Instead of reducing distribution shift to a single score, \cite{UrbanSyn} conduct a comparative distribution analysis of the Cityscapes, GTA‑V, and Synscapes datasets. Their analysis shows that GTA‑V and Synscapes both deviate from Cityscapes, but in different ways. These findings are consistent with our own results (see Appendix~\ref{sec:datasetAnalysis}). Furthermore, they also trained DeepLabV3+ and SegFormer models on each dataset. The reported downstream performance aligns with our findings: SegFormer consistently outperforms DeepLabV3+. Models trained on Cityscapes perform best when tested on Cityscapes, while models trained on GTA-V perform worst.

\section{Analysis of street scene datasets}
\label{sec:datasetAnalysis}
This section presents our analysis of the metric summaries for the three pure training datasets (Cityscapes100, Synscapes100, GTAV100) and the test dataset to gain a deeper insight into prominent differences in dataset characteristics. Across summaries, our Cityscapes-based training and test sets show nearly identical properties, as both were curated from the same underlying distribution.

\subsection{Photorealism (color and texture analysis)}
GTA-V exhibits a pronounced color and texture shift, whereas Synscapes' color and texture properties remain largely consistent with those of Cityscapes. 
Both shifts might be artifacts of GTA-V's underlying rendering approach, which relies on real-time game-engine rendering and thus trades off photorealism against rendering speed, limiting illumination, reflection, and shadow accuracy compared to physically based rendering \cite{UrbanSyn}.

\paragraph{Color}
A comparison of hue, saturation, and brightness distributions (see Figure~\ref{fig:sumColor}) shows that hue and brightness are most strongly affected by this shift. In contrast to \cite{zhang2020}, we do not observe an oversaturation in GTA-V images. However, \cite{zhang2020}  also attribute part of the color shift to differing illumination conditions, which is consistent with our findings. GTA-V images exhibit increased brightness, which may create the perceptual impression of higher saturation due to the Hunt effect \cite{huntEffect}. Furthermore, GTA-V's hue distribution is sharply bimodal, peaking in orange and blue, while the other datasets show a broader, green-dominated distribution. This reflects the geographic setting of each dataset, as GTA-V is set in California, whereas Cityscapes and Synscapes depict Central European cities.

\subsection{Label analysis}
Both Synscapes and GTA-V exhibit a pronounced label shift relative to Cityscapes, but the nature of this shift differs between datasets: The shift in class frequency (Figure~\ref{fig:sumClassFrequency}) is more pronounced for GTA-V, whereas the shift in class presence (Figure~\ref{fig:sumClassPresence}) and scene complexity (Figure~\ref{fig:sumSceneComplexity}) is more pronounced for Synscapes.

\paragraph{Class frequency}
The overall ranking of classes is closely tied to size relations. For example, roads often occupy a larger number of pixels than traffic signs. \cite{zhang2020} note that label distributions implicitly encode information on such underlying idiosyncrasies of urban traffic scenes.
Synthetic and real datasets are fairly close in pixel share for common, large-area classes (e.g., ‘road’, ‘building’, ‘vegetation’, and ‘sky'). Such classes naturally occupy a larger number of pixels in any street scene, and hence, are less susceptible to label shift.

    \label{fig:sumClassFrequency}
\end{figure}

\paragraph{Class presence}
The overall class ranking between class frequency and class presence remains similar. Class presence and pixel proportion are closely related: Classes present in more samples also tend to occupy a larger total pixel area.
Consistent with \cite{zhang2020, liu2022_labelShift, UrbanSyn}, we find that GTA-V's label shift is concentrated in specific classes, with substantially higher representation of ‘terrain’, ‘fence’, ‘wall’, and ‘truck’, and lower representation of 'bicycle’, ‘rider’, and ‘sign’. We attribute this to the dataset’s bias toward American-style urban layouts and traffic participants.
In contrast, Synscapes exhibits a more even class presence across classes.

\paragraph{Scene complexity}
Both synthetic datasets exhibit a higher scene complexity than Cityscapes.
GTA-V shows a moderate increase in the number of distinct classes per sample. This may partly reflect our dataset curation, during which rural images recorded between urban areas were removed (see Section~\ref{sec:datasetPreparation}), as such scenes typically contain fewer distinct classes than dense urban environments.
Synscapes exhibits the highest scene complexity overall. Combined with its even class presence and comparatively high class frequency, this points to a general overrepresentation of classes, which was also reported by \cite{UrbanSyn}.

\subsection{Distribution analysis}
GTA-V exhibits a more prominent shift than Synscapes under both feature extractors (see Figure~\ref{fig:sumMeans}). Note that absolute distances are not comparable across extractors, as StreetCLIP embeddings are L2-normalized while DINOv2 embeddings are not. The consistent ranking across both extractors suggests that the shift reflects a genuine appearance and semantic difference rather than an artifact of a specific feature space.

Furthermore, GTA-V's eigenvalue spectrum lies consistently below that of Cityscapes and Synscapes (see Figure~\ref{fig:sumCovariate}). This suggests a lower variance, and thus reduced visual diversity, within the dataset. Our finding aligns with \cite{synscapes}, which hypothesize that GTA-V's reduced geometric and rendering complexity results in a smaller feature space.
